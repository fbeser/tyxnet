# Security policy

TyxNet is pre-1.0, unaudited and not recommended for production. Security fixes
target the latest main branch; no supported release line exists yet.

Report vulnerabilities privately through GitHub Security Advisories for
`fbeser/tyxnet`. Include affected revision, reproduction, impact and suggested
mitigation. Do not include real credentials or private traffic. Maintainers aim
to acknowledge within 7 days, coordinate validation/remediation and publish an
advisory after a fix. Please allow a reasonable remediation window before public
disclosure.
